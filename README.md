# Expense Tracker Web Application

A simple and interactive Expense Tracker Web Application built using **HTML, CSS, and JavaScript**. This project allows users to enter their expense category and amount, track their total expenses, and visualize their spending through a bar chart.

The application provides an easy way to record daily expenses and understand spending patterns through graphical representation.

## Features
- Add expenses by entering the expense type and amount.
- Calculate and display total expenses.
- Visualize expenses using a bar chart.
- Simple, interactive, and user-friendly interface.
- Responsive design for a better user experience.

## Technologies Used
- **HTML** – Structure of the application.
- **CSS** – Styling and layout.
- **JavaScript** – Expense calculations, interactivity, and chart functionality.

## Purpose
The main objective of this project is to help users manage and monitor their expenses easily while improving their understanding of spending habits through visual representation.

## Future Enhancements
- Save expense records using Local Storage.
- Add expense editing and deletion functionality.
- Include date-wise and category-wise expense analysis.
- Add monthly expense reports and budget limits.

## Conclusion
This project demonstrates the practical use of HTML, CSS, and JavaScript to build an interactive web application for basic expense management and data visualization.
